# Software, Data, Cloud, and Platform

Use for software engineering, data engineering, backend, QA automation, cloud/platform, DevOps, observability, internal tools, dashboards, and infrastructure software leads.

## Promote

- Co-op, intern, student, early talent, or university program labels.
- Backend, platform, distributed systems, internal tools, developer productivity, APIs, databases, ETL, analytics engineering, SRE-adjacent, DevOps, CI/CD, observability, monitoring, and dashboards.
- Roles using languages, frameworks, cloud platforms, databases, Linux, Docker, Kubernetes, Terraform, data pipelines, BI, or test automation supported by the candidate's resume evidence.

## Manual Review

- Generic IT/helpdesk roles unless they include scripting, automation, systems, cloud, data, or infrastructure value.
- Senior developer roles or requirements above the candidate's experience.
- Security roles requiring clearance, citizenship, permanent residency, or deep SOC experience.

## Resume Lane

Default to `software-data`. Use another lane only when the role is embedded, hardware-adjacent, controls-adjacent, manufacturing, utility technology, or domain-specific.
