# Data Center, Cloud Infrastructure, and Network Operations

Use for data center, hyperscaler, network infrastructure, critical environment, NOC, observability, hardware operations, power/cooling monitoring, and facility-adjacent roles.

## Promote

- Cloud infrastructure software, network automation, infrastructure monitoring, SRE-adjacent, observability, dashboards, internal tools, data platforms, and AI infrastructure.
- Data center technician or facility roles only when student, intern, co-op, trainee, junior, entry-level, or paid-training compatibility is plausible.
- Known infrastructure employers where brand, referral, pay, or learning value is strong.

## Manual Review

- Security clearance, long residency, citizenship/PR, driver's license/vehicle, rotating shifts, heavy lifting, electrical/mechanical trade credentials, 2+ years data center operations, 4+ years facility operations, licensed trades, rural relocation, or bilingual requirements.

## Resume Lane

Use `software-data` for software/infrastructure roles. Use `industrial-automation-ot` or a configured domain lane for hardware/facility-adjacent roles only when the candidate has supporting evidence.
