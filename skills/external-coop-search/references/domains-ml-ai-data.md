# ML, AI, and Data Science

Use for machine learning, data science, analytics, applied AI, research engineering, AI tooling, and model evaluation roles.

## Promote

- Student/intern/co-op ML, data science, analytics, AI tooling, data platform, or research software roles.
- Roles whose required tools and math match the candidate's evidence.
- Applied ML roles where software/data engineering proof can carry the application.

## Manual Review

- PhD-only, publication-heavy, senior production ML, deep CUDA/kernel, biomedical/clinical, or specialized research roles not supported by the private material bank.
- Roles that require a portfolio or paper list the candidate does not have.

## Resume Lane

Start from `software-data` unless config defines a stronger ML/DS lane. Elevate ML proof only where supported.
