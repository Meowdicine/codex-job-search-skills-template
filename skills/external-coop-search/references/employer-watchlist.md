# Employer Watchlist Template

Customize this private/public mix for the candidate's market.

## Common Public Search Buckets

- Software and data: banks, telecom, SaaS, health tech, fintech, public sector, analytics platforms.
- Cloud and infrastructure: hyperscalers, data center operators, AI infrastructure, telecom, network equipment, managed services.
- Industrial and utilities: automation vendors, energy companies, mining tech, utilities, industrial software, manufacturing systems.

## How To Use

- Prefer official careers pages.
- Keep a private list of referral contacts outside this public repo.
- Treat public mirrors as discovery, not proof, unless no official posting can be reached.
