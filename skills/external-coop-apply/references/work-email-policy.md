# Work Email Policy Template

Use this only if the candidate explicitly authorizes Codex to inspect a job-search email account for the current task.

## Allowed With Explicit Authorization

- Search and read job-search messages relevant to the current employer portal.
- Extract a one-time verification code or reset link and use it on the live portal.
- Summarize application confirmations or recruiter messages.
- Draft replies for user review.

## Not Allowed Without Action-Time Approval

- Sending any email.
- Deleting, archiving, forwarding, or labeling messages.
- Granting OAuth/account-linking permissions.
- Changing passwords.
- Reading unrelated personal email.

## Logging Rules

- Do not print, store, screenshot, or log verification codes, recovery codes, reset tokens, cookies, session tokens, passwords, or full message bodies.
- Log only that email verification was completed or blocked.
- Narrow searches with employer names, portal names, sender domains, dates, and job-search terms.
